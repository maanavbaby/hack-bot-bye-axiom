# Telegram Sender Bot

A simple Telegram bot that asks for:

- Chat ID
- Bot Token
- Message Text

Then sends the message using the provided bot token.

## Features

✅ Ask Chat ID  
✅ Ask Bot Token  
✅ Ask Message Text  
✅ Send message instantly
